Forgot your recovery key too?

The recovery key is a separate secret only you hold — it was never stored in this app. If you've lost it, it can be reset the same way it was first created (via wrangler secret put ADMIN_RECOVERY_KEY), so it's worth keeping a copy somewhere safe like a password manager.
